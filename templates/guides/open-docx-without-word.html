Quick answer: you don't need to buy Word. Microsoft's own Word for the web is free with a Microsoft account, and Google Docs, LibreOffice and Apple's Pages all open and edit .docx files for free. If you only need to read or print it, convert it to a PDF.

1. Word for the web

Go to office.com (or onedrive.live.com), sign in with a free Microsoft account, and upload the file. It opens in a browser version of Word that handles everyday documents with the same formatting as desktop Word. Some advanced features, such as mail merge and some layout tools, are only in the paid desktop app. Your file is saved to OneDrive; download it with File → Save As → Download a Copy.

2. Google Docs

Upload the file to drive.google.com, then double-click it. Google shows a preview; click Open with Google Docs to edit it. You can edit it as a .docx directly (you'll see a ".DOCX" badge next to the name), or save it as a Google Doc with File → Save as Google Docs. To send it back as Word, use File → Download → Microsoft Word (.docx). Our guide Google Docs vs DOCX explains what can change on the way.

3. LibreOffice Writer

LibreOffice is a free, open-source office suite from libreoffice.org. Its word processor, Writer, opens .docx files, works offline and has no account or adverts. It's the same engine SwapDoc uses for its conversions. When saving, choose Keep Current Format to stay in .docx.

If the document uses Microsoft fonts you don't have, LibreOffice uses stand-ins. Calibri, Cambria, Arial and Times New Roman have exact matches; others may move text slightly. See why fonts change.

4. Pages (Mac, iPhone, iPad)

Pages is free from Apple. Double-click the .docx, or open it from Pages with File → Open. Pages converts it into a Pages document. To send it back, use File → Export To → Word. Pages is great for reading and light editing, but complex Word layouts, comments and tracked changes may not come back exactly as they were.

5. Word on your phone

The Microsoft Word app (or the Microsoft 365 app, which includes it) for iPhone and Android lets you open, read and make basic edits with a free Microsoft account. Some features need a subscription.

6. Just need to read or print it? Make it a PDF

Convert the file with our Word to PDF converter and it opens in any web browser, on any device, ready to print. If the file arrived by email, Gmail and Outlook can also preview .docx attachments without downloading them.

What about WordPad?

WordPad, which came with Windows for decades and could open .docx files, has been removed from recent versions of Windows 11. It also never handled much formatting. Use Word for the web or LibreOffice instead.

Got a .doc file instead?

All of the options above open old .doc files too. If one won't, convert it to .docx first with our DOC ⇄ DOCX converter, and read DOC vs DOCX for the differences.

Frequently asked questions

How can I open a DOCX file for free?
Word for the web, Google Docs, LibreOffice or Pages.
Which free app keeps Word formatting best?
Word for the web, then LibreOffice.
Can I open a DOCX on Windows without Word?
Yes: Word for the web in a browser, or LibreOffice. WordPad is no longer included in recent Windows 11.
How do I just view or print a DOCX file?
Convert it to PDF, or preview it in Gmail or Outlook.
