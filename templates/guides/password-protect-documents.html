Quick answer: in Word for Windows, use File → Info → Protect Document → Encrypt with Password. For a PDF, tick Encrypt the document with a password in the Options when you save as PDF from Word. Send the password separately from the file, never in the same email.

First: open password or editing restrictions?

OptionWhat it doesStops people reading it?
Password to open (encryption)The file is scrambled and can't be opened without the passwordYes
Restrict editing / password to modifyPeople can open and read it but are discouraged from changing itNo
Mark as FinalShows a banner asking people not to editNo

If the document is private, you need a password to open. The other options stop accidental edits; they're not security.

Word for Windows

  1. Open the document and go to File → Info.
  2. Click Protect Document → Encrypt with Password.
  3. Type a password, click OK, and type it again to confirm.
  4. Save the document.

To remove it later, repeat the steps, delete the password so the box is empty, and save.

Word for Mac

  1. Open the Review tab and click Protect Document (it may be under Protect).
  2. Under Set a password to open this document, type a password, and confirm it.
  3. Click OK and save.

PDF from Word for Windows

  1. Go to File → Save As and choose PDF as the file type.
  2. Click Options….
  3. Tick Encrypt the document with a password and click OK.
  4. Type and confirm the password, then save.

PDF from LibreOffice (free, Windows, Mac, Linux)

  1. Open the document in LibreOffice Writer.
  2. Choose File → Export as PDF and open the Security tab.
  3. Click Set Passwords and enter an open password. You can also set a separate permissions password that restricts printing and copying.
  4. Click Export.

PDF on a Mac

In Preview, choose File → Export as PDF and look for the Permissions or Encrypt option (it depends on your macOS version) to require a password to open the file.

Choosing and sharing the password

  • Make it long: three or four random words (for example copper-lantern-river-oat) are stronger and easier to type than a short jumble.
  • Send it another way: text it, say it on the phone, or use a different app. If the email is intercepted or sent to the wrong person, the file stays locked.
  • Don't lose it: Microsoft can't recover a forgotten Word password, and neither can anyone else. Keep it in a password manager.
  • Keep an unprotected original somewhere safe if you'll need to change the document later.

Converting protected files

A file that needs a password to open can't be converted by SwapDoc or any other converter, because it can't be read. Remove the password (if you're allowed to), convert, then add the password to the converted file. Frequently asked questions

How do I password-protect a Word document?
Windows: File → Info → Protect Document → Encrypt with Password. Mac: Review → Protect Document.
How do I password-protect a PDF for free?
Word's Save As PDF → Options → Encrypt the document with a password, or LibreOffice's Export as PDF → Security.
What if I forget the password to my Word document?
It can't be recovered, so keep it in a password manager.
Is Restrict Editing the same as a password?
No. People can still open and read the document.
