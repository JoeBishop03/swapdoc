Quick answer: on a Mac, drag PDFs into Preview's thumbnail sidebar. On an iPhone, select them in Files and choose Create PDF. On Windows, use a free app such as PDFsam Basic. If you're starting from Word documents, combine them in Word first and make one PDF.

Mac: Preview (built in)

  1. Open the first PDF in Preview.
  2. Choose View → Thumbnails to show the page sidebar.
  3. Drag the next PDF from Finder into the sidebar. Drop it between pages, or after the last page, wherever it should go.
  4. Repeat for any other files. Drag thumbnails up and down to reorder pages.
  5. Choose File → Export as PDF to save the combined file under a new name.

To remove a page, select its thumbnail and press Delete. Check the page order in the sidebar before you export.

iPhone and iPad: Files app

  1. Open the Files app and go to the folder with your PDFs.
  2. Tap Select (in the ⋯ menu on newer versions) and tap each PDF in the order you want them.
  3. Tap the More button (⋯) and choose Create PDF.

The combined PDF appears in the same folder. Rename it with a long press → Rename.

Windows: free desktop apps

Windows doesn't include a PDF merger, but these free apps work on your own computer, so your files aren't uploaded anywhere:

  • PDFsam Basic (pdfsam.org): free and open source. Choose Merge, add your files, put them in order, and click Run.
  • PDF24 Creator (pdf24.org): a free toolbox for Windows with merge, split and compress tools.

Download apps only from their official websites, and decline any extra software offered during installation.

Online tools

Free online PDF mergers, including Adobe's, are quick for everyday documents. For anything confidential, such as bank statements, ID or medical letters, a desktop app or the Mac and iPhone tools above are safer because the files never leave your device.

Starting from Word documents? Combine them first

If your PDFs started life as Word files, merging the Word documents and making one PDF gives a cleaner result, with page numbers running all the way through.

  1. Open the first document in Word and click where the next one should start (usually the end). Insert a page break with Ctrl + Enter if needed.
  2. Go to Insert → Object (click the small arrow) → Text from File.
  3. Choose one or more Word files. Hold Ctrl to pick several; they're inserted in alphabetical order, so number the file names if order matters.
  4. Check the result, then make one PDF with File → Save As → PDF, or upload it to our Word to PDF converter.

If some of the files are old .doc documents and won't insert cleanly, convert them with our DOC ⇄ DOCX converter first.

After merging

  • Check the order and that no pages are missing.
  • Check the size. Merging several large PDFs creates a large file; see{% if guide_live('reduce-pdf-file-size') %} how to reduce a PDF's file size{% else %} our guides for tips on shrinking pictures{% endif %}.
  • Give it a clear name, such as Application-Jane-Smith-all-documents.pdf.

Frequently asked questions

How do I merge PDFs on a Mac for free?
Preview → View → Thumbnails, then drag the other PDFs into the sidebar.
How do I merge PDFs on Windows for free?
Use a free desktop app such as PDFsam Basic or PDF24 Creator.
How do I combine PDFs on an iPhone?
Files app → Select → choose the PDFs → More → Create PDF.
Can I merge Word documents before making a PDF?
Yes: Insert → Object → Text from File, then save as one PDF.
