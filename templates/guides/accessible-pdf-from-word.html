Quick answer: build the document properly in Word, with real headings, alt text on pictures, header rows on tables and clear link text, then save it with File → Save As → PDF. Don't use "Print to PDF", which strips out everything a screen reader needs.

Why it matters

People who are blind or partially sighted often use screen readers, which read documents aloud and let you jump between headings. Others zoom in, use high-contrast settings, or have the text re-flowed on a small screen. All of that depends on the PDF knowing what each part of the page is. A PDF that is just "text in positions" leaves them guessing.

In the UK, public sector bodies have legal duties to make documents they publish accessible, and the Equality Act 2010 applies to services more widely. Accessible documents are also easier for everyone to read and search.

Seven things to fix in Word

1. Use real headings

Apply Heading 1, Heading 2 and so on from the Home tab's Styles, rather than just making text big and bold. Screen readers announce headings and let people jump between them. Word also turns them into PDF bookmarks. Use one Heading 1 for the title and don't skip levels.

2. Add alt text to pictures

Right-click a picture and choose View Alt Text (or Edit Alt Text). Describe what it shows and why it's there, in a sentence or two. For a chart, give the key finding ("Sales doubled between 2024 and 2026"). If a picture is just decoration, tick Mark as decorative.

3. Give tables a header row

Click in the table, then on Table Design tick Header Row. On the Layout tab, select the first row and click Repeat Header Rows; this also marks it as a header for screen readers. Avoid merged and split cells where you can, and never use tables just to lay out a page.

4. Write meaningful link text

"Read the guide to PDF or Word" makes sense when read on its own; "click here" doesn't. Screen reader users often list all the links on a page.

5. Use proper lists

Use the bullet and numbering buttons rather than typing dashes or numbers. Then the PDF knows it's a list and how many items it has.

6. Check colour and contrast

Dark text on a light background, and never colour alone to carry meaning. For example, "items in red are overdue" doesn't work for everyone; add a word or symbol too.

7. Set the title and language

Go to File → Info and fill in Title under Properties. Screen readers announce it when the PDF opens. Check the language under Review → Language → Set Proofing Language.

Run Word's checker

Go to Review → Check Accessibility. Word lists errors and warnings, such as missing alt text, tables without headers and hard-to-read colours, with a fix for each. Work through them until none are left.

Save it the right way

Word for Windows

  1. File → Save As, choose PDF.
  2. Click Options… and make sure Document structure tags for accessibility is ticked. Tick Create bookmarks using: Headings too.
  3. Save.

Word for Mac

Use File → Save As and choose PDF, and pick Best for electronic distribution and accessibility if offered.

Avoid "Print to PDF"

Microsoft Print to PDF and similar printer drivers produce a flat picture of the page layout with no tags, bookmarks or reading order. Whatever work you did in Word is lost.

Check the finished PDF

  • Bookmarks: open the bookmarks panel in your PDF reader. Your headings should be listed.
  • Copy test: select all, copy, and paste into Notepad. The text should come out in a sensible order.
  • Read aloud: Adobe Acrobat Reader has View → Read Out Loud, and Microsoft Edge has Read aloud for PDFs. Listen to a page or two.
  • Full check: Adobe Acrobat Pro has a full accessibility checker, and the free PAC tool (from the PDF/UA Foundation) checks against the PDF/UA standard.

Checklist

  1. Headings use Heading styles, in order.
  2. Every meaningful picture has alt text; decorative ones are marked decorative.
  3. Tables have a header row and no layout-only tables.
  4. Links describe where they go.
  5. Lists use Word's list buttons.
  6. Good contrast, and colour isn't the only signal.
  7. Title and language are set.
  8. Review → Check Accessibility shows no errors.
  9. Saved with File → Save As → PDF, with structure tags on.

Frequently asked questions

What makes a PDF accessible?
Tags, reading order, alt text, a title and language, and good contrast.
Does Print to PDF make an accessible PDF?
No. Use File → Save As → PDF.
How do I check a Word document for accessibility?
Review → Check Accessibility.
