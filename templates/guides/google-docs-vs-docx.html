Quick answer: Google Docs is Google's free online word processor, and a "Google Doc" is a document that lives in your Google Drive. DOCX is the file format of Microsoft Word. They aren't the same thing, but they work together well: Google Docs can open, edit and download .docx files, so the real question is usually where to keep a document and what to send people.

The key difference: an online document vs a file

A .docx is a normal file. You can keep it on your laptop, a USB stick, OneDrive or anywhere else, email it as an attachment, and open it without an internet connection.

A Google Doc isn't really a file you hold. It lives on Google's servers and you open it in a web browser (or the Google Docs app). If you use Google Drive on a computer, Google Docs appear as small .gdoc shortcuts: they're links that open the document online, not the document itself. To send a Google Doc to someone who doesn't use Google, you share a link or download a copy in another format.

Editing a DOCX in Google Docs (without converting)

You don't have to turn a Word file into a Google Doc to work on it.

  1. Upload the .docx to Google Drive.
  2. Double-click it and choose Open with → Google Docs.
  3. You'll see a .DOCX label next to the file name. Your edits are saved back into the Word file, so it stays a .docx.

This is handy for quick changes to a Word file someone sent you. For anything longer, converting gives you all of Google Docs' features.

How to convert DOCX to Google Docs

  1. Open the .docx in Google Docs as above.
  2. Go to File → Save as Google Docs. Google creates a new Google Doc and keeps the original Word file untouched.

To convert every Word file you upload automatically, open Google Drive's Settings (the gear icon) and turn on Convert uploads.

How to convert a Google Doc to DOCX

  1. Open the document in Google Docs.
  2. Go to File → Download → Microsoft Word (.docx).

Google Docs doesn't offer the older .doc format. If someone needs one (for example for Word 2003 or older business software), download the .docx and convert it with SwapDoc's free DOCX to DOC converter.

The same menu also offers PDF, OpenDocument (.odt), Rich Text (.rtf), plain text, web page and EPUB. To send a finished copy that looks the same everywhere, PDF is usually best: see PDF or Word: which format should you use?

What changes when you switch between them

Most everyday documents convert cleanly both ways. The things most likely to change:

  • Fonts. Google Docs has its own font list. A Word font it doesn't have is replaced with a similar one, which can change spacing and page count.
  • Text boxes, shapes and SmartArt. These may become pictures or drawings, or move.
  • Complex layouts. Multiple sections, columns, and pictures set to float around text can shift.
  • Track Changes and comments. Word's tracked changes become suggestions in Google Docs, and comments come across. Going the other way, suggestions usually become tracked changes in Word.
  • Macros. Removed, as Google Docs doesn't run Word macros.
  • Pageless documents. If you use Google Docs' pageless setting, the downloaded .docx is split into normal pages, so check where the page breaks fall.

If something looks wrong after converting, our guide to fixing formatting after converting covers the usual culprits.

Which should you use?

Use Google Docs when…

  • several people need to write or comment on the same document at once;
  • you work across different computers, a Chromebook or your phone;
  • you want automatic saving and history without thinking about it.

Use Word and DOCX when…

  • someone asks for a Word document, such as a recruiter, publisher, client or university;
  • the document has a complex layout, or is very long, like a dissertation or book;
  • you need to work offline reliably.

Send a PDF when…

the document is finished and you want it to look exactly the same for everyone, like a CV, invoice or signed letter.

Tips for moving between Google Docs and Word

  • Stick to common fonts available in both, such as Arial, Georgia, Times New Roman or Verdana.
  • Use heading styles (Heading 1, Heading 2) rather than just making text bigger and bold. They survive conversion and keep the structure.
  • Keep one master copy. Converting back and forth repeatedly is how formatting slowly drifts. Decide where the document "lives" and export from there.
  • Resolve comments and suggestions before downloading a copy to send, unless you want the other person to see them.

Common questions

Is a Google Doc the same as a DOCX file?
No. A Google Doc is an online document in Google Drive; a DOCX is a Word file. Google Docs can open, edit and download DOCX files, so switching is easy.
Can Google Docs edit a DOCX without converting it?
Yes. Open it from Google Drive and your changes are saved back to the Word file. Look for the .DOCX label next to the file name.
How do I save a Google Doc as a Word document?
File → Download → Microsoft Word (.docx).
Do comments and suggestions survive?
Usually: comments become Word comments and suggestions become tracked changes. Resolve them first if you don't want them in the copy you send.
Can Microsoft Word open a Google Doc?
Not directly. Download it as .docx first. Need the older .doc format? Convert the download with the DOC ⇄ DOCX converter, and see DOC vs DOCX for the difference.
How do I turn a Google Doc into a PDF?
Use File → Download → PDF document in Google Docs, or download it as .docx and use SwapDoc's Word to PDF converter.
