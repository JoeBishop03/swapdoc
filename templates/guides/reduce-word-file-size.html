Quick answer: compress the pictures (Picture Format → Compress Pictures, applied to all), turn off embedded fonts if you don't need them, and save as .docx rather than .doc. Pictures are the cause nine times out of ten.

Step 1: find out what's taking the space

A .docx file is really a zip folder, so you can look inside:

  1. Make a copy of the document (always work on a copy).
  2. Rename the copy so it ends in .zip instead of .docx. If you can't see file extensions on Windows, turn them on in File Explorer under View → Show → File name extensions.
  3. Open the zip. Look in word/media for pictures and in word/embeddings for embedded spreadsheets and other objects. File sizes are listed next to each one.
  4. Delete the copy when you're done.

This tells you which fix below will help most.

Step 2: compress the pictures

  1. Click any picture, then Picture Format → Compress Pictures.
  2. Untick Apply only to this picture.
  3. Tick Delete cropped areas of pictures. Word otherwise keeps the hidden, cropped-off parts.
  4. Choose 150 ppi for on-screen documents or 220 ppi for printing, then OK.

To make Word do this automatically for this document, go to File → Options → Advanced, find Image Size and Quality, tick Discard editing data, make sure Do not compress images in file is unticked, and set the default resolution.

Insert pictures at a sensible size

For future documents, resize big photos before inserting them, or use phone photos at a smaller size. A picture shown 10 cm wide on a page doesn't need to be 4,000 pixels wide.

Step 3: remove embedded fonts

If File → Options → Save → Embed fonts in the file is ticked, every font used is stored in the document, which can add several megabytes. Untick it unless you need other people to see an unusual font in the Word file itself. If you do need it, also tick Embed only the characters used in the document and Do not embed common system fonts.

If the font only matters in the final version, send a PDF instead: it carries the fonts anyway. See why fonts change in a PDF.

Step 4: replace embedded objects

A chart copied from Excel and pasted normally can carry the entire workbook with it. If the chart doesn't need to be edited in Word, right-click it, Cut, then use Paste Special → Picture (PNG). The same applies to embedded PowerPoint slides and other objects.

Step 5: save as .docx

The old .doc format isn't compressed. When we tested SwapDoc's DOC ⇄ DOCX converter, a 30 KB .doc came back as a 15 KB .docx, with the text, table, picture, comments and tracked changes all intact. In Word, use File → Info → Convert, or File → Save As and choose Word Document (.docx).

Step 6: save a fresh copy

A document that has been edited for years can carry leftovers. File → Save As under a new name writes a clean file. Also check for:

  • Tracked changes and comments, which keep deleted text in the file. See removing tracked changes and comments.
  • Hidden content, found with File → Info → Check for Issues → Inspect Document.

Frequently asked questions

Why is my Word document so big?
Full-size pictures, embedded fonts, embedded objects, or the old .doc format.
How do I compress all pictures in Word at once?
Picture Format → Compress Pictures, untick "Apply only to this picture".
How can I see what is taking up space in a Word file?
Rename a copy to .zip and look in word/media and word/embeddings.
Does saving as DOCX make a file smaller than DOC?
Usually. In our test, 30 KB became 15 KB.
