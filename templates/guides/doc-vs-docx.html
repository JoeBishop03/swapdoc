Quick answer: both are Microsoft Word documents. .doc is the older format, used by Word 97 to Word 2003. .docx replaced it in Word 2007 and has been the default ever since. It's smaller, safer and works better with other apps, so save in .docx unless someone specifically asks for .doc.

What is a .doc file?

.doc was Word's main format for many years. The version you'll meet today is the one used from Word 97 to Word 2003, often labelled "Word 97-2003 Document". It's a binary format: the text, formatting and pictures are packed into a single file whose structure only programs that understand it can read. Microsoft published the full specification in 2008, which is why other programs can open .doc files reliably today.

What is a .docx file?

.docx arrived with Word 2007. Inside, a .docx is a compressed folder (a ZIP file) of text files written in XML, following an open standard called Office Open XML (ECMA-376, later ISO/IEC 29500). You can see this for yourself: copy a .docx, rename the copy to end in .zip, and open it. You'll find a folder called word holding the document text, styles and any pictures.

Why .docx is better

  • Smaller files. The contents are compressed, so documents, especially ones with pictures, usually take up less space and are quicker to email.
  • Easier to recover. Because each part is stored separately, a damaged file can often be partly rescued. A damaged .doc is frequently a lost cause.
  • Safer. Ordinary .docx files can't contain macros (small programs). Documents with macros must be saved as .docm, so you can tell them apart at a glance.
  • Works everywhere. As an open standard, .docx is read well by Google Docs, Apple Pages, LibreOffice and most phone apps.
  • All of Word's features. Some newer features aren't available in .doc, which is why Word opens such files in Compatibility Mode.

Are .doc files dangerous?

Not by themselves, but .doc files can carry macros, and malicious macros have been one of the most common ways malware spreads by email. Modern versions of Word block macros in files downloaded from the internet by default, which has helped a lot. Still:

  • Be wary of unexpected .doc or .docm attachments, even from people you know.
  • Never click Enable Content or Enable Macros on a document unless you trust where it came from and know why it needs them.
  • A .docx is safer, but not risk-free. Treat any attachment you weren't expecting with care.

How to tell whether you have .doc or .docx

Windows and Mac hide file extensions by default. To show them:

  • Windows 11: in File Explorer, click View → Show → File name extensions.
  • Windows 10: in File Explorer, open the View tab and tick File name extensions.
  • Mac: in Finder, choose Finder → Settings → Advanced and tick Show all filename extensions.

Or just open the document in Word. If you see Compatibility Mode next to the name at the top of the window, it's an older .doc (or a .docx saved to behave like one).

In Word for Windows

  1. Open the .doc file.
  2. Go to File → Info → Convert, then click OK.
  3. Save. Word now treats it as a .docx and Compatibility Mode disappears.

In Word for Mac, or any version

Use File → Save As and choose Word Document (.docx) as the format.

Without Word

  • Google Docs: upload the file to Google Drive, open it with Google Docs, then File → Download → Microsoft Word (.docx).
  • LibreOffice (free): open the file, then File → Save As and pick Word 2007-365 (.docx).

After converting, scroll through and check the layout. Occasionally line spacing or page breaks move slightly, because Word lays out upgraded documents using its newer rules. Keep the original until you're happy.

When might you still need .doc?

Rarely. Occasionally an old piece of business software, an older online form, or someone still using Word 2003 or earlier needs .doc. If so, save a copy with File → Save As and choose Word 97-2003 Document (*.doc). Word will warn you if anything in the document can't be kept in the older format. No Word?
